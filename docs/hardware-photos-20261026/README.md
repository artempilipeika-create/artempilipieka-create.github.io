# Supplier photographs for hardware selection

Replaces the generated cabinet views in hardware-choice cards with 24 locally served supplier product photographs. Cargo FOCUS, ICON and NORWING images follow the selected module width and exact BAZIS kit article (11 combinations). Pull-out dryers cover NORWING 600/700/800 and FLAT LINE 600/700/800/900 (7 combinations). Unavailable combinations stay disabled.

Drawer slides, AQ LineBox, Slimbox and upper MOUNT use explicitly labelled series photographs; the photograph does not change the selected manufacturing kit. AQ and LIRA lighting options show their product photographs. Full-width cards, contained images and larger image areas make the mechanisms legible. Native previews remain the fallback. Source URLs, articles, pixel sizes and file hashes are in sources.json.

The dishwasher catalogue card uses an open integrated dishwasher photograph from Bosch, labelled “Пример техники”; dishwasher-source.json records provenance. The previous image is retained as dishwasher-before.webp.

Validation: mocked local browser checks passed for all 11 cargo and 7 dryer article mappings, drawer and lighting options, mobile 390 px layout, read-only preview updates, actual selection and exact undo. The dishwasher image loads at 1600 × 1200. No JavaScript errors or unexpected network requests. See validation.json and screenshots. No production orders or project data were submitted. Geometry, dimensions, manufacturing rules and the 3D scene are unchanged.
