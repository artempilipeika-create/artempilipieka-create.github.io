# Выдвижная сушка и размеры пеналов

Отдельная карточка «Шкаф с выдвижной сушкой» содержит 12 проверенных по SHA-256 FR3D: NORWING / FLAT LINE, шариковые / AQ LineBox / Slimbox Evolution, накладные ручки / Gola II. Сверху сушка, снизу один ящик. В обычную карточку шуфляд эти варианты не добавляются.

Ширины NORWING: 600, 700, 800 мм. FLAT LINE: 600, 700, 800, 900 мм. Произвольные ширины отклоняются в UI, сохранении API и актуальном импортере БАЗИС. При переходе с FLAT LINE 900 на NORWING сначала нужно явно выбрать меньшую ширину. Артикулы комплектов считываются из встроенных таблиц FR3D; корзина закупается одним комплектом, без повторной закупки её вложенных деталей. Глубина 510–700 мм: уменьшение ниже проверенного исходника не разрешено.

Исправленный исходник AQ LineBox + NORWING без Gola от 25.10.2026: `НМРШ2-600.З.С 3мм Гвозди. Ящик AQ LineBox.NORWING(1).fr3d`, SHA-256 `6c26baab4b7a7bbc1c9b2eecb49112ffd97147ea176f3eb696318bc22b32cf0b`. Корзина находится внутри корпуса: X=18, Y=478,5, Z=60 мм; размер 562 × 220 × 450 мм. Остальные панели, эластика и комплекты полностью совпадают с предыдущей версией. Предупреждение о положении корзины снято. Каталожный ID сохранён; только известный предыдущий SHA автоматически обновляется в UI, API и импортере. Неизвестные версии не подменяются. Нативный БАЗИС в этой среде не запускался.

Кнопка «Вровень с верхними» задаёт высоту пенала по верхней отметке выбранного навесного шкафа, с учётом отметки установки самого пенала. При нескольких шкафах доступен явный выбор; первым предлагается ближайший с тем же поворотом. Это разовое изменение, доступное для отмены, а не постоянная связь. Ниши духовки и СВЧ и нижняя секция сохраняют высоту.

## Выравнивание всех пеналов и витрин

Общий блок «Выравнивание пенала» доступен у пеналов с полками, под технику и у всех витрин Z1. Он расположен перед настройками семейства. Кнопка «Вровень с верхними» работает во всех этих вариантах.

Кнопка «От стены до линии фасадов» пересчитывает глубину и положение пенала по выбранному нижнему шкафу с тем же поворотом. Наружная задняя плоскость пенала касается стены; наружная плоскость закрытого фасада совпадает с фасадом нижнего шкафа. Учитываются выступ задника пенала с полками 3 мм, фасад 18 мм, наружная плоскость рамки Z1 22,5 мм и фактический задний отступ нижнего модуля, включая Gola. Внутренний технический канал пенала под технику сохраняется. Например, для нижнего корпуса 510 мм с задним отступом 50 мм глубина корпуса пенала с полками получается 557 мм, под технику — 560 мм, витрины — 555,5 мм.

При пристыковке пенала сбоку к нижнему ряду у стены глубина подгоняется автоматически. При привязке отдельного пенала к стене внешний зазор равен нулю. Изменение глубины уже установленного у стены пенала удерживает его заднюю плоскость. Глубина пеналов допускает шаг 0,5 мм, координата центра — 0,25 мм; эти значения сохраняются без округления в API и JSON-экспорте БАЗИС. Ограничения размеров каждого семейства и проверка пересечений остаются обязательными. Выравнивание разовое: после изменения выбранного нижнего или верхнего шкафа его можно применить повторно; Undo/Redo поддерживаются.

Проверка этой правки: 132 теста Node и 38 тестов Python. Проверены все варианты пеналов, четыре поворота, обычный нижний шкаф и Gola, фактические передние и задние плоскости деталей, точность сохранения и повторного открытия. Локальный браузерный сценарий проверил кнопки для трёх семейств, ручную глубину, Undo/Redo, сохранение/открытие и JSON-экспорт БАЗИС. API браузерного сценария подменён; нативный БАЗИС не запускался.

Пеналы с полками: глубина 300–700 мм. При уменьшении глубины корпус, перегородка и полки уменьшаются до заданного размера; фасады и задник следуют новым плоскостям корпуса. Размер сохраняется в проекте, деталировке, PDF и экспорте БАЗИС. Пеналы под технику: глубина 500–700 мм, ширина 600 мм. Корпус и полки следуют глубине, сохраняются задний канал 50 мм и ниши 595/380 мм. Техника не сжимается; монтаж конкретной модели сверяется по её инструкции. У вариантов с шуфлядой сохраняется не менее 50 мм между ящиком и задником: глубина 500–549 мм → ящик и направляющие 400 мм (114795), 550–599 мм → 450 мм (114796), от 600 мм → исходные 500 мм (114797). Дно на 4 мм короче боковин. Артикулы и крепёж взяты из проверенного кэша FR3D `bazis.3a209387ab60`; схема и деталировка, PDF и закупка используют один выбор. В примечаниях экспорта БАЗИС указана проверка/ручная корректировка укороченного ящика и направляющих; нативный БАЗИС здесь не запускался.

Документация посудомойки Gola L использует обычный чёрный профиль AKS 60965 вместо 89731. Это явное поле `documentation_profile`; исходные материал, геометрия и SHA FR3D остаются доступными для аудита. Светодиодный профиль не попадает в закупочную ведомость. При изготовлении использовать обычную Gola по ведомости.

Проверка: 63 теста Node (сушка, геометрия, переключения, пеналы, Gola), 38 тестов Python (API, ширины, SHA, паритет спецификаций и PDF). Отдельный локальный UI-тест проверяет FLAT LINE 900 / артикул 95551, запрет NORWING 900, глубину пенала 650, выравнивание и Undo, отсутствие горизонтального переполнения на телефоне. API в UI-тесте полностью подменён; заказы, почта и платный рендер не запускаются.

## Изменение высоты верхних шкафов

При изменении высоты верхнего шкафа его нижняя отметка фиксируется в `elevation_mm`: увеличение поднимает верх, уменьшение опускает только верх. Для старых проектов без этого поля исходный низ берётся из прежней формулы помещения в момент изменения; при открытии старые шкафы не перемещаются. Отметка сохраняется в JSON проекта, Undo/Redo, копировании и замене верхнего модуля; общий расчёт используется в WebGL, старом Canvas, PDF и позиции Y экспорта БАЗИС. Выход выше потолка отклоняется, шкаф вниз автоматически не сдвигается.

## Gola относительно столешницы

Для всех проверенных нижних модулей Gola (двери, ящики, выдвижная сушка и посудомойка) передний край столешницы выступает перед номинальной лицевой плоскостью закрытого фасада на 0,5 мм. Номинальный фасад — 18 мм; микросмещения исходных FR3D до 0,0082 мм сохранены без изменения деталей. Фактическая привязка сзади рассчитывается как глубина столешницы − глубина корпуса − 18,5 мм. Для корпуса 510 и столешницы 600 это 71,5 мм. Обычные модули сохраняют задний зазор 50 мм.

При загрузке старого проекта Gola смещается один раз относительно сохранённого заднего края столешницы. При переключении исполнения, изменении глубины корпуса/столешницы и замене модуля задний край столешницы удерживается. Соседние модули разных исполнений объединяются по линии столешницы. Геометрия панелей, профилей и исходные SHA не изменяются. Координаты, свес и привязка сохраняются в проекте, производственных примечаниях и экспорте БАЗИС.

Проверка: 116 тестов Node (геометрия, 20 источников Gola, четыре поворота, ряды, углы, смена исполнения и глубины) и 68 тестов Python (API, сохранение и документация). Два теста наличия исходных accessory FR3D исключены: эти бинарные файлы отсутствуют в локальном checkout и в этой правке не менялись. Локальный браузерный сценарий с подменённым API проверил реальные переключатели, глубины, сохранение/открытие и JSON-экспорт: z = 21,5 мм и задний зазор 71,5 мм для корпуса 510 / столешницы 600. Заказы и повторный фоторендер не запускались.
