# Larger Tripo catalogue cards and kitchen finishes

The fourteen cabinet families now have larger, single-column product cards with shorter captions and new Tripo Studio images. Existing geometry-reviewed catalogue images were supplied as references. Production models, dimensions and export/BOM routines are unchanged.

A separate **Отделка кухни** catalogue category contains **Столешницы**, **Скинали** and **Цоколь** tabs. Existing controls are moved into these panels, so selections and history remain shared with the inspector. The inspector backsplash shortcut opens the new category and correct tab. Tab keyboard navigation supports arrows, Home and End. Appliance-tall layout diagrams are enlarged and selected choices use blue outlines.

The image manifest records the Tripo job IDs and subscription usage. The production WebPs are 890 × 635 exports of visually reviewed generated previews; no 4K or paid generation was requested.

Validation: 63 unit tests, focused desktop/mobile catalogue navigation, three finish panels, euro joint and SKIF panel selection, automatic plinth, undo, countertop save/reopen/export, and seven open-tall configurations with height/front alignment. Browser API writes were mocked; no production orders or messages were sent.
