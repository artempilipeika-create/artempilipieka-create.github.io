Martin Forest — импортёр БАЗИС 9.9.2

Координаты
Минимальные габариты всей импортированной сборки устанавливаются на X=0 и Z=0.
Сдвиг общий для всех модулей. Высоты Y, повороты и взаимные расстояния сохраняются.
Учитываются фактические габариты БАЗИС, включая выступающие детали.
Другая координата задаётся константами ASSEMBLY_LEFT_X_MM и ASSEMBLY_MIN_Z_MM.

Материалы
Обновлённый сайт дожидается загрузки выбранных материалов перед экспортом.
Корпус и обычные шуфляды используют выбранную плиту 18 мм; детали металлоящиков
сохраняют отдельный материал 16 мм; тонкие днища и задники — отдельный ЛХДФ.
Импортёр проверяет полное название с артикулом и толщину после назначения
и после Commit. Если штатное назначение оставило прежнее имя, применяется
запись полного имени MaterialName с повторной проверкой. Ошибки создания,
чтения и назначения материалов теперь видны в итоговом окне и журнале.
Материал не выбирается наугад, если в экспорте нет нужных данных.

Установка и запуск
1. Сохранить прежний импортёр вне Scripts и заменить единственный действующий
   импортёр файлом из архива.
2. Обновить страницу конструктора. Проверить выбранный материал корпуса;
   для металлоящиков отдельно проверить материал плиты 16 мм.
3. Скачать свежий JSON проекта и запустить импортёр в новой пустой модели БАЗИС.
4. Проверить X=0.000, Z=0.000 и число подтверждённых материалов в итоговом окне.
5. Сохранить B3D самостоятельно.

Если корпус или шуфляды остались со старым материалом, для точной диагностики
передать JSON этого проекта и созданный рядом *.import-v9_4_3.log.txt.
Расширение журнала историческое; внутри указана фактическая версия 9.9.2.
Причина последнего пользовательского случая без этих файлов не подтверждена.

Папки FR3D
Вложенные папки поддерживаются как раньше. Общая папка задаётся LIBRARY_ROOT.
Перенос того же FR3D между категориями не требует изменения карточек.

Проверка
68 автоматических проверок прошли. API БАЗИС проверялся на имитации;
БАЗИС на ПК в этой среде не запускался. Версия X-only 9.9.1 подтверждена пользователем.
