Martin Forest — импортёр БАЗИС 9.9.1

Левый край всей импортированной сборки устанавливается на X=0 мм.
Взаимное положение модулей, повороты, высоты и координаты Z сохраняются.
Для привязки используются габариты БАЗИС, включая выступающие детали.
При необходимости другая координата задаётся в начале скрипта:
const ASSEMBLY_LEFT_X_MM = 0;

Установка
1. Сохранить копию прежнего импортёра вне папки Scripts.
2. Заменить единственный действующий импортёр файлом из этого архива.
3. Скачать экспорт проекта с сайта.
4. Открыть новую пустую несохранённую модель в БАЗИС и запустить импортёр.
5. В итоговом окне проверить строку «Левый габарит всей сборки: X=0.000 мм».
6. Сохранить модель как B3D самостоятельно.

Папки FR3D
Можно свободно раскладывать модули по вложенным папкам внутри общей папки
«Модули Для Мартин форест»: например, Нижние/Gola/Ящики, Верхние/Сушка,
Пеналы/Духовка. Скрипт ищет FR3D рекурсивно и проверяет точное содержимое
по SHA-256 из экспорта. Перемещение и переименование того же FR3D допустимы.
Если изменяется сама общая папка, исправить LIBRARY_ROOT в начале скрипта.
Изменённый внутри БАЗИС FR3D — новая версия модуля: его нужно отдельно
согласовать с карточкой сайта. Файл с тем же именем не подменяет исходник.
Сортировка не создаёт новые карточки и не копирует FR3D на сайт.

Проверка
52 автоматические проверки прошли, включая сдвиг сборки, повороты,
выступающий фасад, возврат при ошибке, вложенные папки и настройки ящиков/Gola.
Проверки API выполнены на имитации. Сам БАЗИС в этой среде не запускался.
